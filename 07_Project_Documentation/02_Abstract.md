# Abstract

AI FitTrack is a full-stack fitness tracking application developed to provide users with a simple way to record and manage workout information while receiving AI-assisted fitness recommendations and insights. The backend is developed using Node.js and Express.js, with MongoDB used for data storage. Authentication and workout management are exposed through REST APIs.

The project also integrates Google Gemini to generate workout recommendations based on user information and fitness goals, and to generate insights from workout statistics. Postman is used for API testing. A React and Vite frontend foundation is also included to provide a user-facing interface. The system demonstrates the practical integration of REST API development, database management, authentication, frontend development, and generative AI in a student-level full-stack project.
