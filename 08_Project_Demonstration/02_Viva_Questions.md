# Viva Questions and Short Answers

## 1. What is AI FitTrack?
It is a fitness tracking application that combines workout management with AI-generated recommendations and insights.

## 2. Why Node.js?
Node.js allows JavaScript to be used for backend development and is suitable for building REST APIs.

## 3. Why Express.js?
Express.js provides a simple framework for creating routes, middleware, and REST APIs.

## 4. Why MongoDB?
MongoDB is a document-oriented database that works naturally with JavaScript-based applications.

## 5. What is REST API?
A REST API allows applications to communicate through HTTP methods such as GET, POST, PUT, and DELETE.

## 6. What is Gemini used for?
Gemini is used to generate workout recommendations and fitness insights from supplied user/workout data.

## 7. What is Postman?
Postman is used to send API requests and verify API responses.

## 8. What is React?
React is a JavaScript library used to build user interfaces.

## 9. Why is `.env` important?
It stores configuration and sensitive values such as API keys outside the source code.

## 10. What is the main limitation?
The current frontend foundation still requires complete API integration and further UI development.
