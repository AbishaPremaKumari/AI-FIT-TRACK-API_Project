# Phase 5 – Project Development: Backend

## Backend Stack
- Node.js
- Express.js
- MongoDB
- JWT-based authentication
- Google Gemini API

## Implemented Modules
### Authentication
Registration, login, and profile retrieval were implemented and tested.

### Workout Management
The project supports creation, retrieval, searching, updating, and deletion of workout records.

### AI Assistant
The backend contains services for:
- Workout recommendation
- Fitness insights

The Gemini model is read from the `GEMINI_MODEL` environment variable so the model can be changed without hard-coding it into the source.

## Development Environment
Visual Studio Code and Windows PowerShell were used during development.
