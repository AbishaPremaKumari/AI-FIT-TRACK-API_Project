# Software and Hardware Requirements

## Software
- Windows 10/11
- Visual Studio Code
- Node.js
- npm
- MongoDB
- MongoDB Compass (optional)
- Postman
- Google Chrome
- Git
- GitHub account
- Google Gemini API access

## Hardware
- Laptop/Desktop computer
- Minimum 4 GB RAM recommended
- Internet connection for AI API access and GitHub operations

## Development Environment
Backend: Node.js + Express.js
Database: MongoDB
Frontend: React + Vite
Testing: Postman
